You type a game's code inside that game, not on the Roblox website. Most of the 30 popular games in this guide put the code box in the Shop, in Settings, or behind a button with a bird icon or the word Codes. Of those 30, 14 keep it somewhere in the Shop.

I've grouped the 30 games by where the box is. The spots come from the redeem steps on each game page. Games sometimes move buttons in updates, so if one has moved, [tell me](/contact/) and I'll fix the steps.

## Look for these icons first

Before you open every menu, check the edges of the screen for one of these:

- **A Shop or Store button**, sometimes a shopping cart. This is the most common spot. In the games here it's usually on the left side or in the bottom-left corner.
- **A bird icon**, like the old Twitter logo. In the three games here that have one, it opens the code box.
- **A gear (cog).** That's Settings. Three games here put the code box inside it.
- **A button that says Codes.** It can be small, so look closely.
- **A gift box or a "123" icon.** These are rarer. In the games here, both sit inside another menu.

## In the Shop

### Scroll down the Shop

Open the Shop (some games call it the Store) and scroll down. In most of these games the code box is at the very bottom, so it's easy to miss.

- [2 Player Raid Tycoon](/2-player-raid-tycoon-codes/) (Store)
- [Blue Lock Farm](/blue-lock-farm-codes/)
- [Case Simulator RNG](/case-simulator-rng-codes/)
- [Immortality Incremental](/immortality-incremental-codes/) (scroll until you reach the Codes section)
- [Merge a Nuke!](/merge-a-nuke-codes/) (Store)
- [Roll a Fisherman](/roll-a-fisherman-codes/)
- [+1 Loot To Forge](/plus-1-loot-to-forge-codes/) (the Shop button is a trolley icon)

Two of these games also say where the box is in their Roblox descriptions. The [Case Simulator RNG description](https://www.roblox.com/games/125906853713277/Case-Simulator-RNG) says its code goes at the bottom of the shop, and the [2 Player Raid Tycoon description](https://www.roblox.com/games/126710589265077/2-Player-Raid-Tycoon) says to use its code in the shop.

[Taxi Boss](/taxi-boss-codes/) is close to this group. Its Shop opens from a shopping cart in the bottom-left corner, and the Enter Code box is in the shop window.

### A Codes tab inside the Shop

Look for a tab or button called Codes, Code or Redeem, usually along the top of the Shop window.

- [Anime Fighting Simulator](/anime-fighting-simulator-codes/)
- [Gym Star Simulator](/gym-star-simulator-codes/) (the tab is called Code)
- [Drag Drive Simulator](/drag-drive-simulator-codes/) (the tab is called Redeem)
- [Midnight Chasers: Highway Racing](/midnight-chasers-highway-racing-codes/) (press Play on the main menu first)
- [Dudes Battlegrounds](/dudes-battlegrounds-codes/) (the Shop is the icon near the top right, a blue diamond in the current version)

[Squid Game X](/squid-game-x-codes/) is the odd one: its Codes button is in the bottom-right corner of the Shop, not along the top.

## In Settings

Tap the gear to open Settings. In Dog Race and Slop Tower Defense!, the code box is at the bottom of the menu.

- [Dog Race](/dog-race-codes/): gear in the top-right
- [+1 Power Per Click](/plus-1-power-per-click-codes/): gear on the right side, near the top
- [Slop Tower Defense!](/slop-tower-defense-codes/): cog on the left side. You need at least 10 wins before codes work.

## Behind a bird button

- [Bubble Gum Simulator](/bubble-gum-simulator-codes/): top-left. Make sure you're in the original game, not Bubble Gum Simulator Infinity.
- [Saber Simulator](/saber-simulator-codes/): right side, just below Settings.
- [Tower Defense Simulator](/tower-defense-simulator-codes/): check from the lobby. Reports differ on where the button sits, so look on the left side first, then the top right.

## A Codes button on the screen

The button sits right on the screen, so you only need to spot it.

- [Beatball](/beatball-codes/): bottom-left of the lobby
- [Murderers VS Sheriffs](/murderers-vs-sheriffs-codes/): top-right of the lobby
- [+1 Skate Trickz Escape](/plus-1-skate-trickz-escape-codes/): left side
- [untitled boxing game](/untitled-boxing-game-codes/): left side
- [Dream Car Collection](/dream-car-collection-codes/): a small purple button in the bottom-right. If it isn't there, try the bottom of the Store.

## Hidden inside another menu

These take an extra tap, so they are easy to miss.

- [Anime Astral Simulator](/anime-astral-simulator-codes/): the Menu button in the top-right, then Codes.
- [BlockSpin](/blockspin-codes/): the menu icon on the right, then the Codes tab. Pick promo or referral to match your code.
- [Drift 36](/drift-36-codes/): the small arrow in the top-left, next to the chat icon, then Codes.
- [+1 DMG FPS](/plus-1-dmg-fps-codes/): Rewards on the left, then the Code option with the "123" icon.
- [Retro Tower Defense](/retro-tower-defense-codes/): Inventory on the left, then the gift box icon in the top-right of that window.

## Games that want the tutorial done first

In some games, the code box stays hidden or won't work until you've finished the opening tutorial. If you're new, play through it first in:

- [2 Player Raid Tycoon](/2-player-raid-tycoon-codes/) (also claim your side of the factory)
- [Beatball](/beatball-codes/)
- [Case Simulator RNG](/case-simulator-rng-codes/) (some reports say you also need to reach Level 10)
- [Dog Race](/dog-race-codes/) (a tutorial banner can cover the code box)
- [Roll a Fisherman](/roll-a-fisherman-codes/)
- [+1 Loot To Forge](/plus-1-loot-to-forge-codes/)

## Still can't find it?

- **Wait for the game to load.** Buttons can take a moment to appear after you spawn.
- **Close pop-ups.** They can cover the button or the box, like the tutorial banner in Dog Race.
- **Check the game's description on Roblox.** Roblox's rules say developers must publish code offers somewhere public, such as the game's description ([Roblox Help](https://en.help.roblox.com/hc/en-us/articles/10549651908244-Promo-Offers-for-Virtual-Rewards)). The 30 games in this guide list their codes there, and two of them also say where the box is.
- **Look around the spawn area.** A game with no code button may put the code box on a machine in the world instead. None of the 30 games above work this way.

If you found the box but the code won't go through, see [why a Roblox code isn't working](/guides/roblox-code-not-working/).

## Game codes don't go on roblox.com/redeem

The box at [roblox.com/redeem](https://www.roblox.com/redeem) is for Roblox gift cards and Roblox promo codes ([Roblox Help](https://en.help.roblox.com/hc/en-us/articles/360029650831-How-Do-I-Redeem-a-Promo-Code)). Game codes come from each game's developer, and Roblox's rules say those rewards can only be used in that game, so you enter them in the game's own code box.
