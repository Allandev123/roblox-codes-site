It depends on the kind of code. A code for one game goes in the code box inside that game. A Roblox promo code or a gift card goes on [roblox.com/redeem](https://www.roblox.com/redeem), which you open in a web browser.

## The three kinds of Roblox codes

Three different things all get called "Roblox codes". That makes it easy to type a code into the wrong box. Here is how they compare.

| Kind of code | Cost | Where you type it | What you get |
|---|---|---|---|
| In-game code | Free | The code box inside that one game | Cash, boosts or items for that game only |
| Roblox promo code | Free | roblox.com/redeem, in a web browser | A virtual item, Robux or Credit, depending on the code |
| Gift card | Paid | roblox.com/redeem, in a web browser | Robux or Roblox Credit |

### In-game codes

These come from the people who make a game. They often post them in the game's description on its Roblox page, and some also post them on social media or Discord. You type them into a code box inside the game, and the reward only works in that game.

Roblox's [rules for game promo offers](https://en.help.roblox.com/hc/en-us/articles/10549651908244-Promo-Offers-for-Virtual-Rewards) say these rewards must be usable only in that game. They also say players should not have to pay or trade anything to redeem them. So you should never have to pay for an in-game code.

For example, a code from the [Taxi Boss](/taxi-boss-codes/) description goes in the Enter Code box in the Taxi Boss shop. It will not work in any other game, and it will not work on roblox.com/redeem.

### Roblox promo codes

These come from Roblox itself, for example from [events or giveaways](https://en.help.roblox.com/hc/en-us/articles/360029650831-How-Do-I-Redeem-a-Promo-Code). Codes that come with official Roblox toys and some partner offers go in the [same place](https://en.help.roblox.com/hc/en-us/articles/360000316606-How-to-Redeem-Toy-Virtual-Item-Codes).

Roblox says promo codes may expire or only work for a short time, so use yours soon. You may see older posts that send you to roblox.com/promocodes. That address now forwards to roblox.com/redeem, so it is the same box.

### Gift cards

Gift cards cost real money. They add Robux or Roblox Credit to your account. Amazon and Party Packs gift cards give Robux only, according to [Roblox's gift card help page](https://en.help.roblox.com/hc/en-us/articles/115005566223-How-to-redeem-and-spend-your-Gift-Card). If you have more than one card, enter them one at a time.

## Which box does my code go in?

Look at where the code came from.

- **From a game's description or the game's social media or Discord:** it is an in-game code. Type it in that game's code box.
- **From a gift card someone paid for, in a shop or online:** use roblox.com/redeem.
- **From Roblox, a Roblox toy or a partner offer:** use roblox.com/redeem.

## How to redeem an in-game code on any device

The code box is part of the game, not part of your phone or console. So the steps are mostly the same on every device:

1. Open the game and wait for it to load. Some games want you to finish the tutorial first.
2. Find the code button. Many games use a Codes button, or put the box inside the Shop or Settings menu.
3. Select the code box and type the code exactly as written.
4. Press the button next to the box. It is usually called Redeem, but some games say Claim, Enter or Submit.

Games put the box in different places. In [Dog Race](/dog-race-codes/), it sits at the bottom of the Settings menu. In Taxi Boss, it is inside the Shop. Each game's page on this site lists the steps for that game, and the [where to enter Roblox codes](/guides/where-to-enter-roblox-codes/) guide covers the most common spots.

Some games treat capital and small letters as different. `START` and `start` might not be the same code, so copy the capitals too.

### On a PC or Mac

Click the code box and type the code. Copying and pasting the code stops typos. Paste with Ctrl+V on Windows or Cmd+V on a Mac.

### On a phone or tablet

Phone keyboards can change what you type, and that can break a code.

- **Turn off auto-capitalization and autocorrect** before you type a code. On an iPhone or iPad, go to Settings, then General, then [Keyboard](https://support.apple.com/guide/iphone/type-with-the-onscreen-keyboard-iph3c50f96e/ios). On Android with Gboard, open the Gboard settings and tap [Text correction](https://support.google.com/gboard/answer/9058584). You can turn them back on afterward.
- **To paste**, tap the code box, then press and hold inside it and choose Paste. If Paste does not show up, type the code by hand.
- **Check for spaces.** When you copy a code, it is easy to grab a space before or after it.

### On Xbox or PlayStation

Select the code box with your controller, then type the code with the on-screen keyboard. Roblox's help pages for [Xbox](https://en.help.roblox.com/hc/en-us/articles/207850783-What-can-I-do-on-Roblox-on-Xbox) and [PlayStation](https://en.help.roblox.com/hc/en-us/articles/19880023697428-What-can-I-do-on-Roblox-on-PlayStation) show the on-screen keyboard being used to type chat messages inside games.

Both pages also say you can connect a USB or Bluetooth keyboard to your console to type. Either way, check each letter before you press the button.

## How to redeem promo codes and gift cards

Both use the same page. These are the steps from the [Roblox Help Center](https://en.help.roblox.com/hc/en-us/articles/115005566223-How-to-redeem-and-spend-your-Gift-Card):

1. Open a web browser and go to [roblox.com/redeem](https://www.roblox.com/redeem).
2. Log in to the Roblox account you want the reward on.
3. Type your code in the box.
4. Click **Redeem**. A message tells you when it worked.

Roblox says you cannot redeem these codes in the standard mobile app or on a console. On a phone, use the phone's web browser instead of the Roblox app. The one exception is the Roblox app on Samsung Galaxy devices. There, open the **More** page and tap the **Redeem** tile.

If you play on Xbox or PlayStation, redeem the code in a browser on a phone or computer. Log in with the same account you use on your console, since [Robux belong to your account](https://en.help.roblox.com/hc/en-us/articles/360029481932-Where-are-my-Robux), not to one device.

> Tip: if a gift card code gives an error, Roblox suggests swapping characters that look alike: 0 (zero) and O, 1 (one) and I, 5 and S, or 8 and B.

## Watch out for "free Robux" codes

Roblox's Help Center says: "There is no such thing as free Robux or subscription offers, tricks, or codes." Any person, video, website or game that says otherwise is running a [scam](https://en.help.roblox.com/hc/en-us/articles/204262550-Free-Robux-or-Subscription-Generators).

- No real code needs you to share your password. Only type your password on the Roblox login page.
- A real in-game code is free. If someone asks you to pay, trade or fill in a survey to get a code, do not do it. Roblox says online surveys are one of the most common ways players lose their accounts.
- Roblox [announces its own promotions](https://en.help.roblox.com/hc/en-us/articles/203313380-Keep-Your-Account-Safe) on its blog, in your Notifications, or with a banner on the Roblox website.

If you see a scam, report it with the Report Abuse button in the app or inside the game. The [free Robux code scams](/guides/free-robux-codes-scams/) guide shows the common tricks.
