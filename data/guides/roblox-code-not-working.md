A Roblox code usually fails for one of three reasons: it has expired, it was typed a little differently from the original, or the game wants you to do something first. Work through the checks below from the top. The first few take seconds.

## The code has expired

Game codes belong to each game's developers, not to Roblox, and the developers decide when a code ends. Many codes are tied to a milestone. [Taxi Boss](/taxi-boss-codes/) thanks players for 600K likes with `THX600K` and says the next code comes at 800K. [Midnight Chasers: Highway Racing](/midnight-chasers-highway-racing-codes/) shows one "Current Code", `ThanksFor980k`, and says the next one comes at 1M likes. When a new code arrives, the old one may be switched off.

Codes named after a season can end the same way. [Saber Simulator](/saber-simulator-codes/) lists `FALL26` as a new code in its change log, and a code like that may stop working once the season is over.

**How to fix it:** open the game's page on this site. A program reads every game's Roblox page every 3 hours, and when a game stops listing a code, the code moves to that page's expired list ([how I check codes](/how-we-check-codes/)). A developer can also switch a code off before taking it out of the description, so if a code on my list fails for you, [let me know](/contact/).

## The capital letters don't match

Some games treat capital letters as part of the code, so `FallPart2` in [Bubble Gum Simulator](/bubble-gum-simulator-codes/) might fail if you type `fallpart2`.

Developers don't all use the same style either. [Roll a Fisherman](/roll-a-fisherman-codes/) uses `RELEASE`, [Anime Astral Simulator](/anime-astral-simulator-codes/) uses `Release`, and [untitled boxing game](/untitled-boxing-game-codes/) lists its codes in lowercase, like `deimos`.

**How to fix it:** type the code exactly as the developer wrote it, capitals and all. Copying and pasting is safer than typing.

## A space, symbol or autocorrect got in the way

Every character counts. The code in [Squid Game X](/squid-game-x-codes/) is `$1.2M`, with the dollar sign and the dot. [Slop Tower Defense!](/slop-tower-defense-codes/) has used codes with spaces in the middle. Leave out one symbol, or add an extra one, and the code won't match.

Phone keyboards can cause these mistakes too. They may put a capital letter at the start or "fix" a code into a real word. Pasting can also bring along a hidden space at the start or end.

Some letters and numbers look alike, such as 0 and O, or 1 and I. Roblox's own [gift card help page](https://en.help.roblox.com/hc/en-us/articles/115005566223-How-to-redeem-and-spend-your-Gift-Card) warns about the same mix-ups.

**How to fix it:** paste the code, then check there's no space before or after it. On a phone, you can turn off auto-capitalization and autocorrect in your keyboard settings while you redeem, then switch them back on.

## You already used it on this account

Codes are often limited to one use per account. If you redeemed a code before, even on another device, you won't get the reward a second time.

Referral codes are stricter. In [BlockSpin](/blockspin-codes/), `W7C28D` is for new players only, and each account can use just one referral code.

**How to fix it:** check your cash, items or active boosts. The reward may already be there from last time.

## You typed it in the wrong box, or the wrong game

Roblox has two kinds of codes, and they don't mix:

- **Game codes**, like every code on this site, go in a code box inside that game. Roblox's rules for developers say a code's reward can only be used in the game where it's redeemed ([Roblox Help](https://en.help.roblox.com/hc/en-us/articles/10549651908244-Promo-Offers-for-Virtual-Rewards)).
- **Roblox codes** from gift cards and Roblox's own promotions go on [roblox.com/redeem](https://www.roblox.com/redeem) ([Roblox Help](https://en.help.roblox.com/hc/en-us/articles/360029650831-How-Do-I-Redeem-a-Promo-Code)). Roblox says to use a web browser for these, because the standard mobile app and consoles have no redeem option. The Roblox app on Samsung Galaxy devices is the one exception ([Roblox Help](https://en.help.roblox.com/hc/en-us/articles/115005566223-How-to-redeem-and-spend-your-Gift-Card)).

Also check you're in the right game. [Bubble Gum Simulator](/bubble-gum-simulator-codes/) and Bubble Gum Simulator Infinity are separate games, so make sure you've opened the one the code is for.

**How to fix it:** find the code box inside the game. Some are hard to spot. In [Retro Tower Defense](/retro-tower-defense-codes/), it's a gift box icon in the top-right corner of the Inventory window. My guide to [where games hide the code box](/guides/where-to-enter-roblox-codes/) shows where it is in 30 games.

## You're on an old server

When a developer updates a game, servers that are already running don't switch over straight away. Roblox's [developer docs](https://create.roblox.com/docs/projects/update-games) explain that players move to the new version as old servers empty out and shut down, unless the developer restarts them. So if a code came with a new update, the server you're in may still be running the old version, where that code doesn't exist yet.

**How to fix it:** leave the game and join again from the game's page. If you joined by following a friend, you'll land back in their server, so join on your own instead. If the code still fails, wait a while and try again.

## The game wants something from you first

Some games only accept codes once you've reached a certain point. These are the rules noted on this site's game pages:

| Game | What you need first |
|---|---|
| [Tower Defense Simulator](/tower-defense-simulator-codes/) | Own the tower a skin code is for. `2MILLION` gives the Mercenary Pursuit skin, so you need the Pursuit tower |
| [Slop Tower Defense!](/slop-tower-defense-codes/) | At least 10 wins |
| [Case Simulator RNG](/case-simulator-rng-codes/) | Reach Level 10 |
| [BlockSpin](/blockspin-codes/) | Be a new player to use the referral code. A brand-new account may get an "Alt Account" error until it has played for 10 to 15 minutes |
| [Roll a Fisherman](/roll-a-fisherman-codes/), [Beatball](/beatball-codes/), [+1 Loot To Forge](/plus-1-loot-to-forge-codes/) | Finish the tutorial |
| [2 Player Raid Tycoon](/2-player-raid-tycoon-codes/) | Finish the tutorial and claim your side of the factory |
| [+1 Power Per Click](/plus-1-power-per-click-codes/) | Some codes need a set number of rebirths |

**How to fix it:** play until you meet the requirement, then try the code again.

## Quick checklist

- The code is still listed on the game's page.
- You copied it exactly: capitals, numbers and symbols.
- There's no space before or after it.
- You haven't used it on this account before.
- You're in the right game, using the code box inside it.
- You rejoined after the latest update.
- You've finished the tutorial, or whatever else the game asks for first.
